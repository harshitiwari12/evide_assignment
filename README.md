# Evide Takehome Assignment
# Bus Tracking app
## 🚀 Run Instructions
1. Clone repo
2. Run `flutter pub get`
3. Run app with `flutter run`

## 📂 Features
- Load bus stops from local JSON
- List + detail screen
- Favorites (persistent via SharedPreferences)
- Search filter
- Clean project structure

## 🛠️ Tech
- Flutter
- SharedPreferences
- Local JSON
